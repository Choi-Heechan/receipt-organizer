영수증 정리 플러그인 사용 안내

receipt-organizer · Claude Code 플러그인 · 버전 0.1.1

1. 무엇을 해 주나요

사람별 폴더에 모아 둔 영수증(PDF·JPG·PNG)을 Claude가 읽어서, 상위 폴더에 아래 파일을 만들어 줍니다. (YYYYMMDD = 실행한 날짜)

파일내용
receipt_<폴더명>_YYYYMMDD.xlsx사람별 영수증 목록 (날짜·상호·등록번호·금액·세율·결제 수단·비고)
list_receipt_YYYYMMDD.xlsx폴더별 건수·합계 금액·오류 건수 요약
dashboard_YYYYMMDD.html더블클릭하면 브라우저에서 열리는 사람별 카드 화면 (인터넷 불필요)
receipt_YYYYMMDD.json전체 결과 데이터 (다른 프로그램 연동용)

2. 준비물

  • Claude 유료 요금제(Pro 이상)와 Claude Code — Claude 데스크톱 앱의 「Code」 탭 또는 터미널의 claude 명령. Windows·Mac 모두 사용할 수 있습니다.
  • Python 3 — 처음 실행할 때 Claude가 자동으로 확인하고, 없으면 설치 방법을 안내합니다(아래 7번).
  • GitHub 계정은 필요 없습니다.

3. 설치 (처음 한 번)

Claude Code 대화창에 아래 두 줄을 차례로 입력합니다.

/plugin marketplace add Choi-Heechan/receipt-organizer
/plugin install receipt-organizer@receipt-tools

설치가 끝나면 Claude Code를 다시 시작(새 세션)해 주세요.

예전에 받은 receipt-processor 스킬이 있다면 호출 문구가 겹칩니다. claude.ai → 사용자 지정 → Skills → 내 항목에서 꺼 주세요.

4. 폴더 준비

영수증_2026년10월/          ← 상위 폴더 (실행할 때 지정)
├── 홍길동/                 ← 사람별 폴더
│   ├── 20261003_택시.jpg
│   └── 20261005_식당.pdf
└── 김철수/
    └── ...
  • 지원 형식: .jpg .jpeg .png .pdf — 아이폰 사진(HEIC)은 처리되지 않으니 JPG로 저장해 주세요.
  • 파일 1개 = 영수증 1장으로 처리합니다. 여러 장을 한 PDF에 넣지 마세요.
  • 파일명 앞에 날짜(예: 20261003_)를 붙여 두면, 날짜를 못 읽었을 때 참고로 사용합니다.
  • 사람별 폴더 안의 하위 폴더도 그 사람 영수증으로 처리합니다. 상위 폴더에 바로 놓인 영수증은 처리하지 않습니다.

5. 실행

방법 A — 경로를 함께 입력

영수증 정리해줘 C:\Users\...\영수증_2026년10월

방법 B — 상위 폴더에서 실행

데스크톱 앱에서는 상위 폴더를 작업 폴더로 열고, 터미널에서는 상위 폴더로 cd 한 뒤 claude를 실행합니다. 그리고:

영수증 처리해줘

Claude가 「개인 폴더 N개, 영수증 M건을 찾았습니다. 진행할까요?」라고 확인합니다. 영수증 수에 따라 몇 분 정도 걸립니다.

6. 결과 확인

  • 끝나면 채팅에 폴더별 건수·합계 금액 표와 만들어진 파일 경로가 나옵니다.
  • 読み取りエラー (빨강): 읽지 못한 칸입니다. 금액이 오류면 합계에서 빠집니다 — 원본을 보고 직접 입력해 주세요.
  • 要確認 (노랑): 읽었지만 확인이 필요한 칸입니다(흐림·날짜 불일치 등). 합계에는 포함됩니다. 이유는 「備考」 열에 적혀 있습니다.
  • 등록번호가 원래 없는 영수증은 記載なし로 표시됩니다(오류 아님).
  • 같은 날 다시 실행하면 기존 파일을 덮어쓰지 않고 _2, _3을 붙여 새로 만듭니다.

7. Python이 없다고 나올 때

  • Windows: Claude가 winget install Python.Python.3.12 실행을 제안합니다. 「예」라고 하면 설치합니다. winget이 안 되면 python.org에서 설치하고 첫 화면의 「Add python.exe to PATH」에 체크하세요. 설치 후 Claude를 다시 시작해야 인식될 수 있습니다.
  • Mac: 터미널에서 xcode-select --install을 실행하거나, macOS가 띄우는 설치 창을 따라 주세요.

8. 자주 있는 상황

상황해결
「ファイルを閉じてから再実行してください」Excel에서 해당 파일을 닫고 「다시 실행해줘」라고 말해 주세요.
도중에 끊겼다다시 실행하면 「이어서 할까요?」라고 묻습니다. 이어서 하면 이미 읽은 폴더는 건너뜁니다.
「読み取り結果に含まれていないファイル」빠진 영수증이 있다는 뜻입니다. Claude가 그 파일을 읽고 다시 만듭니다(합계 누락 방지).
처리되지 않은 파일이 있다고 나옴빈 폴더·HEIC 등 미지원 형식·상위 폴더에 바로 둔 파일입니다. 형식이나 위치를 고쳐 다시 실행하세요.

9. 업데이트

/plugin marketplace update receipt-tools

입력 후 Claude Code를 다시 시작하면 새 버전이 적용됩니다.

10. 개인정보

결과 파일은 모두 내 PC의 지정 폴더에만 저장됩니다. 이 플러그인은 별도 서버나 외부 OCR 서비스로 데이터를 보내지 않습니다. 다만 영수증 이미지는 판독을 위해 Claude(Anthropic)에게 전달됩니다 — 평소 Claude에 파일을 보여 주는 것과 같은 방식입니다.

日本語

領収書整理プラグイン 利用ガイド

receipt-organizer · Claude Code プラグイン · バージョン 0.1.1

1. できること

個人フォルダに入れた領収書（PDF・JPG・PNG）を Claude が読み取り、上位フォルダに次のファイルを作成します（YYYYMMDD＝実行日）。

ファイル内容
receipt_<フォルダ名>_YYYYMMDD.xlsx個人別の領収書一覧（日付・店名・登録番号・金額・税率・支払区分・備考）
list_receipt_YYYYMMDD.xlsxフォルダ別の件数・合計金額・エラー件数のまとめ
dashboard_YYYYMMDD.htmlダブルクリックでブラウザに表示される個人別カード画面（インターネット不要）
receipt_YYYYMMDD.json全結果データ（他システム連携用）

2. 必要なもの

  • Claude 有料プラン（Pro 以上）と Claude Code — Claude デスクトップアプリの「Code」タブ、またはターミナルの claude コマンド。Windows・Mac どちらでも使えます。
  • Python 3 — 初回実行時に Claude が自動で確認し、なければインストール方法を案内します（下記 7）。
  • GitHub アカウントは不要です。

3. インストール（初回のみ）

Claude Code の入力欄に次の 2 行を順に入力します。

/plugin marketplace add Choi-Heechan/receipt-organizer
/plugin install receipt-organizer@receipt-tools

インストール後、Claude Code を再起動（新しいセッション）してください。

以前の receipt-processor スキルがある場合は呼び出しの言葉が重なります。claude.ai → カスタマイズ → Skills → 自分の項目 でオフにしてください。

4. フォルダの準備

領収書_2026年10月/          ← 上位フォルダ（実行時に指定）
├── 山田太郎/               ← 個人フォルダ
│   ├── 20261003_タクシー.jpg
│   └── 20261005_会食.pdf
└── 佐藤花子/
    └── ...
  • 対応形式：.jpg .jpeg .png .pdf — iPhone の写真（HEIC）は処理されないので JPG で保存してください。
  • 1 ファイル＝領収書 1 枚として処理します。複数枚を 1 つの PDF にまとめないでください。
  • ファイル名の先頭に日付（例：20261003_）を付けておくと、日付が読めないときの参考にします。
  • 個人フォルダ内のサブフォルダもその人の領収書として処理します。上位フォルダに直接置いた領収書は処理しません。

5. 実行

方法 A — パスを一緒に入力

領収書をまとめて C:\Users\...\領収書_2026年10月

方法 B — 上位フォルダで実行

デスクトップアプリでは上位フォルダを作業フォルダとして開き、ターミナルでは上位フォルダに cd してから claude を起動します。そして：

領収書処理して

Claude が「個人フォルダ N 個・領収書 M 件が見つかりました。処理しますか？」と確認します。件数によって数分かかります。

6. 結果の確認

  • 完了すると、チャットにフォルダ別の件数・合計金額の表と作成ファイルのパスが表示されます。
  • 読み取りエラー（赤）：読み取れなかった項目です。金額がエラーの場合は合計に含まれません。原本を見て手入力してください。
  • 要確認（黄）：読み取ったが確認が必要な項目です（かすれ・日付の不一致など）。合計には含まれます。理由は「備考」列にあります。
  • 登録番号の記載がない領収書は 記載なし と表示されます（エラーではありません）。
  • 同じ日に再実行すると上書きせず、_2、_3 を付けて新しく作成します。

7. Python が見つからないと表示されたら

  • Windows：Claude が winget install Python.Python.3.12 の実行を提案します。「はい」と答えるとインストールします。winget が使えない場合は python.org からインストールし、最初の画面で「Add python.exe to PATH」にチェックしてください。インストール後は Claude の再起動が必要な場合があります。
  • Mac：ターミナルで xcode-select --install を実行するか、macOS が表示するインストール画面に従ってください。

8. よくあるケース

状況対処
「ファイルを閉じてから再実行してください」Excel で該当ファイルを閉じて「もう一度実行して」と伝えてください。
途中で中断した再実行すると「続きから再開しますか？」と聞かれます。再開すると読み取り済みのフォルダはスキップします。
「読み取り結果に含まれていないファイル」読み漏れがあるという意味です。Claude がそのファイルを読んで作り直します（合計の漏れ防止）。
処理されなかったファイルがあると表示される空のフォルダ・HEIC など未対応形式・上位フォルダに直接置いたファイルです。形式や場所を直して再実行してください。

9. アップデート

/plugin marketplace update receipt-tools

入力後に Claude Code を再起動すると新しいバージョンが適用されます。

10. 個人情報について

結果ファイルはすべて自分の PC の指定フォルダにだけ保存されます。このプラグインは別のサーバーや外部 OCR サービスにデータを送りません。ただし領収書の画像は読み取りのため Claude（Anthropic）に送られます — 普段 Claude にファイルを見せるのと同じ方法です。
